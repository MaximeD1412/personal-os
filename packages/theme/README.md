# theme

`tokens.css` : les jetons du design system, importés par les feuilles globales
du tableau de bord et du portfolio. Ils viennent de la bibliothèque pen.dev
(`design/personalos.lib.pen`) ; `nx test theme` vérifie qu'ils n'en dérivent pas.
Voir [`docs/design-system.md`](../../docs/design-system.md).
